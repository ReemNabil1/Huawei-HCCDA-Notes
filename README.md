# HCCDA Study Notes  
**Huawei Certified Cloud Developer Associate**

This repository contains structured study notes for the **Huawei Certified Cloud Developer Associate (HCCDA)** certification.

The notes are written as a **clear, standalone reference** for learning and revision, with a strong focus on:
- Understanding core cloud concepts
- Exam-oriented explanations and traps
- Visual learning using Mermaid diagrams (text-based)

These notes are suitable for:
- Exam preparation
- Concept revision
- Public knowledge sharing
